HOW "FORMS AI" WORKS

The product is an AI-powered Google Forms creation and editing application.

The core flow is:

User
  ↓
Forms AI Login / Signup
  ↓
New Chat
  ↓
User describes what they want
  ↓
AI understands intent
  ↓
┌───────────────────────────────┐
│                               │
│ Normal conversation           │
│ Suggest questions             │
│ Create form                   │
│ Modify existing draft         │
│ Regenerate draft              │
│ Accept suggestions            │
│                               │
└───────────────────────────────┘
  ↓
Form Draft
  ↓
Preview / Editor
  ↓
User manually edits OR asks AI to edit
  ↓
New draft version
  ↓
User explicitly clicks "Create GForm"
  ↓
Google OAuth authorization
  ↓
Google Forms API
  ↓
Google Form created
  ↓
Show Google Form links

The most important architectural rule is:

Chat ≠ Google API side effect

Typing something into chat must never automatically create a Google Form.

Only:

User clicks "Create GForm"

can start the Google Forms publishing process.

Another critical rule:

AI → Draft
Draft → Google Forms

Never:

AI → Google Forms directly

The AI only produces or modifies a structured form draft.
